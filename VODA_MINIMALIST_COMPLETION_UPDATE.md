# Voda Time — Minimalist Completion Update

This pass focuses on production polish and simpler navigation.

## Changes
- Removed the employee Payroll Checkup / Time Health card.
- Reduced dashboard summary cards from eight to four essentials: Pay Period, Regular, Overtime, Pending.
- Removed the Saved Job / Manual one-time selector from Add Hours.
- Kept recent/smart job suggestions for fast reuse of recently entered jobs.
- Removed Start Manual Job from the next-job sheet.
- Removed the saved/manual selector from recorded-shift review.
- Submission routing now closes transient sheets/modals before returning to Timesheets.
- Mobile More sheet automatically closes whenever the active section changes.
- Added consistent light/dark glass surfaces with a lower-cost mobile blur.
- Improved text wrapping rules to prevent mid-word warping in cards and bubbles.
- Added an off-white Voda logo loading screen with a subtle pulse animation for auth and splash states.
- Removed visible temporary/development wording from the application source.
- Preserved existing admin controls, realtime hour syncing, audit history, approvals, exports, weekly overview, and pay-period calendar.
