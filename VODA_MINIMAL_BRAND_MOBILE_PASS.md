# Voda Time — Minimal Brand + Mobile Fit Pass

This pass focuses on clarity, symmetry, mobile fit, and restrained Voda branding.

- Removed Week at a Glance from the employee home screen.
- Dark mode is now the default on first launch; the user's light/dark choice is remembered.
- Rebuilt light-mode glass contrast so text, inputs, panels, and navigation remain readable.
- Changed the top title from Hours Tracking to Portal and reduced its visual size.
- Integrated tightly-cropped transparent Voda circle/dots and Voda wordmark assets.
- Loading uses the circle/dots mark on off-white for a smooth ~1.5 second launch moment.
- Header uses the Voda mark + wordmark without oversized logo boxes.
- Login uses the Voda wordmark and employee portal label.
- Pay-period card gets a very subtle Voda watermark.
- Reworked the two-week calendar into a compact seven-column mobile grid.
- Day tiles now prioritize weekday, short date, hours, and a tiny entry/status indicator; full details remain one tap away.
- Removed the repetitive calendar instruction panel.
- Reduced mobile header action clutter while retaining Settings, theme, and Logout access.
- Added mobile-specific text, date, spacing, blur, and symmetry safeguards.
